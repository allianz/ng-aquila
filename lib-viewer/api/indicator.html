import { NxIndicatorModule } from '@allianz/ng-aquila/indicator';

Components

NxIndicatorComponent

Selector: nx-indicator

Properties
Name Description
Input

overlap: InputSignalWithTransform<boolean, unknown>

Whether the indicator moves inwards to overlap its container. Only affects the 'top-start', 'top-end', 'bottom-start' and 'bottom-end' positions.
Input @Input()

position: string

Sets the indicator positioning preset. Accepts a space-separated list of NxIndicatorPosition values. Unrecognized values are ignored

The legacy positions over-text, over-icon, after-text and with-overlap are ignored when combined with any other position.
Input{ alias: size }

sizeInput: InputSignal<NxIndicatorSize>

Sets the indicator size. Optimized for A1.

Ignored when the indicator sits in a component that provides an NxIndicatorContext: there the host owns the size.
Input

type: InputSignal<NxIndicatorType>

Sets the indicator color type. Optimized for A1.

size: Signal<NxIndicatorSize>

Size the indicator renders at: the hosting context wins over the size input.

Additional interfaces

NxIndicatorContext

Implemented by components that host a projected indicator and want to control its size. Provide the implementation under NX_INDICATOR_CONTEXT.
