Additional classes

NxMessageToastConfig

Configuration used when opening a message toast.

Properties
Name Description

announcementMessage?: string

Message to be announced by the LiveAnnouncer. When opening a toast message without a custom component or template, the announcement message will default to the specified message.

Default: ''.

context?: NxMessageToastContext

Context of the message toast.

Default: 'info'.

data?: D

Data being injected into the child component.

duration?: number

The length of time in milliseconds to wait before automatically dismissing the message toast.

Default: 3000.

politeness?: AriaLivePoliteness

The politeness level for the LiveAnnouncer announcement.

Default: 'polite'.

showContextIcon?: boolean

Whether the context icon is shown.

Default: true.

wrapperId?: string

Id of the aria-live wrapper element that holds the message toasts. Set a unique value when several Angular apps share a page.

Only honored on the root (first-created) service: passing it to open() has no effect, and a value set on a nested/component-level provider is ignored, since child services inherit the parent's region.

Default: 'nx-toast-message-region'.

Additional type aliases

CONTEXT

The contextual type of a message.

'error' and 'success' are deprecated: use 'critical' and 'positive' instead.

Type: 'regular' | 'info' | 'critical' | 'positive' | 'warning' | 'error' | 'success'

BANNER_CONTEXT

The contextual type of a message banner. Banners take every message context but 'regular'.

'error' and 'success' are deprecated: use 'critical' and 'positive' instead.

Type: 'info' | 'critical' | 'positive' | 'warning' | 'error' | 'success'

BANNER_ACTION_LAYOUT

Where the projected actions of a message banner sit relative to its content.

Type: 'horizontal' | 'vertical'

NxMessageToastContext

The contextual type of a message toast.

'success' is deprecated: use 'positive' instead.

Type: 'info' | 'warning' | 'critical' | 'positive' | 'success'
